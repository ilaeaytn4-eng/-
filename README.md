# MULTISHOP BLOG STUDIO — MVP v0.1

직원 로그인 없이 공도점/진사점 블로그 초안을 만드는 Next.js 웹사이트입니다. **실제 배포 전 보안 설정이 필수**입니다.

## 현재 구현
- 매장 선택, 정보형/비교형/홍보형, 주제 입력 또는 자동 선택
- OpenAI Responses API 기반 한국어 블로그 초안 생성/편집/복사
- OpenAI Images API 기반 예시 이미지 **한 장씩** 생성 및 다운로드
- Supabase 연결 시 매장별 공유 초안 저장/열기
- 동일 출처 요청 검사, Upstash Redis 기반 IP별 시간당 제한(원고 8회, 이미지 5회)
- 운영환경에서 Redis 미설정 시 AI 생성 요청 차단(fail closed)

## 아직 구현되지 않은 것
- 공식 자료 실시간 검색 및 검증, 5장 일괄 이미지 생성/자동 배치
- n8n 예약 작업, 네이버 발행 자동화, 관리자 대시보드, 팀별 성과 분석
- 자동 초안 저장 이력 관리, 이미지 장기 저장, 완전한 운영 감사 로그

## 시작하기 (Windows)
1. Node.js 20 이상 설치
2. 폴더에서 `npm install`
3. `.env.example`을 `.env.local`로 복사하고 `OPENAI_API_KEY` 입력
4. `npm run dev` 실행
5. `http://localhost:3000` 접속

OpenAI API 사용료는 ChatGPT 구독료와 별개입니다. 모델 ID는 본인 API 계정에서 사용 가능한 것으로 설정하세요.

## 공유 초안 저장
1. Supabase 프로젝트 생성
2. SQL Editor에서 `supabase.sql` 실행
3. `.env.local`에 `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY` 입력
4. 서버 재시작. 서비스 역할 키는 서버에서만 사용하며 브라우저에 노출하지 않습니다.

## 공개 배포 (Vercel)
1. GitHub 비공개 저장소에 소스 업로드 (`.env.local` 제외)
2. Vercel에서 저장소 연결
3. Vercel 환경변수에 OpenAI, Supabase, Upstash Redis REST 설정
4. 배포 후 `/api/health`에서 설정 여부 확인
5. 직원들에게 사이트 URL 공유

**주의:** '주소만 알면 접근 가능'은 인증이 아닙니다. URL은 유출될 수 있고 IP 제한은 공유 IP/우회 환경에서 불완전합니다. 이 MVP는 비용 제한을 위한 기본 방어만 제공합니다. 실사용 전 전체 일일 비용 한도, 계정 API 예산 제한, 로깅, WAF, 스팸 방지, 초안 수정/삭제 권한 정책을 추가하세요. 서버가 아닌 브라우저에 API 키를 넣지 마세요.

## 매장 정보
`lib/stores.ts`에서 주소와 소개 문구를 관리합니다. 전화번호는 매장별 최종 확인 전이므로 **빈 값**입니다. 정확한 전화번호를 확정한 뒤 수정하세요.

## n8n 연동 계획
기존 n8n 워크플로는 별도 자동화 계층으로 연결합니다. 현재 웹사이트에서 예약 생성 기능이 연결된 상태는 아닙니다.

## v0.2 변경사항
- AI 주제 6개 추천 및 재추천 (`POST /api/topics`, mode=suggest)
- 직접 입력한 주제의 AI 수정안 6개 (`mode=refine`)
- 글마다 이미지 0~5장 선택(기본 3장), 선택 수에 맞는 원고 이미지 삽입 표시
- 이미지 순차 생성, 개별 다운로드 및 재생성
- 주제 추천도 텍스트 API 사용량 제한에 포함됨

**제약:** 이미지 생성은 원고 생성 후 별도 버튼으로 실행합니다. 현재 이미지 데이터는 브라우저 메모리에만 보관되어 새로고침하면 사라집니다. 초안 DB에는 원고만 저장됩니다. 실시간 공식자료 검증과 예약 자동 생성은 미구현입니다. 이미지 5장 요청은 서버 이미지 생성 제한(기본 IP당 시간당 5회)을 소모합니다. 공개 운영 전 예산/쿼터 및 공유 사용량 제한을 조정해야 합니다.
